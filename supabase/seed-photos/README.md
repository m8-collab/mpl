# Gallery seed photos

These are the 17 matchday photos that were previously baked into the site.
Now that the gallery is admin-managed (Supabase Storage), upload them
through the admin panel instead:

1. Open `admin.html` and log in.
2. Go to the **Gallery** tab.
3. Drag-and-drop all 17 files from this folder in (or select them via
   the file picker) and add a short caption for each if you like.

They'll appear on the live Gallery page immediately for every visitor.
